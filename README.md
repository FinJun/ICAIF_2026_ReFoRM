# ICAIF 2026 — ReFoRM

Research website for **From Hindsight to Foresight: Adapting Reusable Reasoning Structures from Recurring Financial Events**.

## Website

Published with GitHub Pages from the root of the `main` branch. No installation or build is needed.

## Contents

- `index.html`: paper introduction, compact author credits, results, qualitative cases, and ICAIF 2026 information.
- `styles.css`: responsive layout and reduced-motion support.
- `app.js`: methodology navigation, model comparisons, and case controls.
- `finance-example.js`: source-linked Fed teaching graph with preserved, reversed-contribution, and excluded-unverified paths.
- `paper.pdf`: supplied manuscript, unchanged.

## Conference

ICAIF 2026: 7th ACM International Conference on AI in Finance, 14–17 November 2026, Milan, Italy, Bocconi University.
Source: https://icaif2026.org/

The site labels the conference without asserting a presentation slot or publication status.

## Evidence and scope

Benchmark numbers and cases are transcribed or paraphrased from Tables 3–5 and Figure 3 of the manuscript. The Fed graph is a manually constructed teaching example, not a reported ReFoRM run. Its selected 2024 evidence predates the target decision. An unverified credit path is excluded from active support without asserting that credit risks disappeared.

The page and all local assets use relative links so they work under a GitHub Pages project path.
